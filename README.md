### 1. 📈 AI Growth
* **Objective**: Maximize customer lifetime value (LTV) and accelerate repurchase frequency without eroding merchant margins.
* **Capabilities**:
  * **RFM Behavioral Segmentation**: Automatically groups customers into *Champions*, *Loyal*, *At-Risk*, and *Dormant* cohorts.
  * **14-Day Repurchase Prediction**: ML models score customer re-order probabilities based on purchase recency gaps and average basket size.
  * **Margin-Safe Re-engagement**: Recommends personalized incentives strictly capped at $\le 10\%$ discount to safeguard gross margins.

### 2. 🛡️ AI Risk Manager
* **Objective**: Intercept fraudulent card testing, account takeovers, and synthetic identity fraud before settlement losses occur.
* **Capabilities**:
  * **Sub-12ms Risk Scoring**: Evaluates international IP distance, Tor/VPN exit node proximity, and 10-minute velocity bursts.
  * **Cash-on-Delivery (COD) Safeguard**: Flags suspicious high-ticket orders for automated phone verification or upfront partial token deposits.
  * **Automated Chargeback Defense**: Assembles representment evidence packages (3DS logs, IP trace, proof-of-delivery receipts) ready for bank submission.

### 3. 🔄 AI Revenue Recovery
* **Objective**: Transform failed payments, abandoned carts, and overdue receivables into recovered merchant revenue.
* **Capabilities**:
  * **Intelligent Failure Diagnosis**: Distinguishes transient bank issuer timeouts (HDFC/SBI netbanking lags) from insufficient card balances.
  * **Smart Retries**: Queues automated background payment retries during peak bank clearance windows (e.g. 11:30 AM).
  * **1-Click WhatsApp & UPI QR Recovery**: Delivers instant, pre-filled Razorpay payment links via WhatsApp.
  * **Dual-Track Debt Recovery Notices**:
    * *Track 1 (Friendly Courtesy Notice)*: Auto-approved friendly reminder for transient payment drops ($<14$ days overdue).
    * *Track 2 (Statutory Legal Notice)*: Formal demand letter drafted under Section 138 of the Negotiable Instruments Act & Indian Contract Act for persistent defaults ($>30$ days), mandating merchant sign-off.

### 4. ⚖️ AI Finance Controller
* **Objective**: Protect operating cash liquidity, forecast payroll/logistics obligations, and eliminate working capital shortfalls.
* **Capabilities**:
  * **Real-time Runway Monitoring**: Continuously tracks liquid bank balances against committed recurring expenses (payroll, logistics, AWS, gateway MDR).
  * **Dynamic Capital Safety Buffer**: Enforces an automated ₹15,00,000 liquidity lock in Razorpay Capital Vault.
  * **30-Day What-If Stress Scenarios**: Real-time sensitivity simulation modeling the impact of revenue shocks (e.g., -20% sales drop, +15% expense spikes).

The Command Center provides founders and finance leaders with an institutional-grade financial control room:

     * *"Why did revenue drop this week?"*

## 🛡️ Zero-Trust Policy & Guardrail Engine

Autonomous systems must never put merchant capital or customer goodwill at risk. Razorpay AI implements a deterministic, multi-layer policy engine (`PolicyEngine`):

| Policy Rule | Condition | Gatekeeper Action |
| :--- | :--- | :--- |
| **Max Discount Cap** | Proposed discount $> 10\%$ | **Hard Reject**: Violates margin protection policy |
| **Friendly Courtesy Notice** | Overdue $< 14$ days, transient drop | **Auto-Approved**: Dispatched via WhatsApp/SMS |
| **Statutory Legal Notice** | Overdue $> 30$ days, Section 138 NI Act | **Requires Sign-off**: Manual merchant authorization required |
| **Budget Expansion** | Outflow dips into ₹15L safety reserve | **Requires Sign-off**: Liquidity warning flag triggered |
| **High-Ticket Transaction** | Transaction $> ₹50,000$ with risk score $> 85$ | **Requires Sign-off**: Flagged for human review |
| **Dispute Representment** | Chargeback status = `UNDER_REVIEW` | **Auto-Approved**: Evidence dossier compiled |

## 🚀 Quick Start Guide

### Prerequisites
* **Node.js**: `v18.0.0` or higher
* **npm**: `v9.0.0` or higher
* **Python**: `3.10+` (optional, for ML microservice)

### 1. Clone the Repository
```bash
git clone https://github.com/LakshayRajput09/Razorpay-AI-Buildathon.git
cd Razorpay-AI-Buildathon
```

### 2. Install Dependencies
```bash
# Install root, frontend, and backend packages
npm install
npm install --prefix frontend
npm install --prefix backend
```

### 3. Configure Environment Variables
Create `.env` inside `frontend/` (or use defaults):
```env
# Database configuration (Defaults to local resilient mock layer if database is offline)
DATABASE_URL="postgresql://neondb_owner:...@ep-silent-meadow-...neon.tech/neondb?sslmode=require"

# Python ML Model Service URL
PYTHON_ML_SERVICE_URL="http://127.0.0.1:8000"

# Optional External LLM Integration (Gemini, Anthropic, or OpenAI)
LLM_PROVIDER="auto"
GEMINI_API_KEY=""
ANTHROPIC_API_KEY=""
OPENAI_API_KEY=""

# Razorpay API Credentials (Sandbox / Simulated)
RAZORPAY_KEY_ID="rzp_test_AiNativeDemoKey101"
RAZORPAY_KEY_SECRET="test_SecretAuthKeyRazorpay2026"
```

### 4. Run the Platform

You can launch all services concurrently or individually:

#### Start Frontend (Next.js — Port 3000)
```bash
npm run dev:frontend
```
Open [http://localhost:3000](http://localhost:3000) to view the application.

#### Start Backend (Node/Express API — Port 5001)
```bash
npm run dev:backend
```
Backend API server listens on [http://localhost:5001](http://localhost:5001).

#### Start Python ML Microservice (FastAPI — Port 8000)
```bash
npm run dev:ml
```
Interactive Swagger API documentation available at [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs).
